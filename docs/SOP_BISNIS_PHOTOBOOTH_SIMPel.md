# SOP Sederhana Menjalankan Bisnis Photobooth

Dokumen ini dibuat untuk dipakai orang non-bisnis. Fokusnya: langkah praktis supaya event jalan lancar dan uang tidak bocor.

## A. Aturan Dasar (Paling Penting)

1. Jangan berangkat event tanpa checklist perangkat.
2. Jangan mulai melayani tamu sebelum test 1 sesi penuh berhasil.
3. Semua transaksi harus tercatat (manual/digital).
4. Kalau ada error, utamakan tetap melayani tamu dulu, baru investigasi teknis.
5. Setelah event selesai, selalu hitung hasil dan catat masalah.

## B. Alur Kerja Harian (Simple)

### 1) Sebelum Event (H-1 atau minimal 3 jam sebelum buka)

- Cek jadwal: jam datang, jam mulai, lokasi, PIC venue.
- Cek paket customer: berapa jam, berapa print, add-on apa.
- Siapkan alat:
  - Android utama + cadangan
  - charger + kabel + terminal listrik
  - kamera (kalau pakai eksternal) + baterai
  - printer + stok kertas/tinta/ribbon
  - backdrop/lighting
- Nyalakan station lokal, test endpoint, login device.
- Test real 1 sesi end-to-end:
  - create event
  - create session
  - capture
  - print
  - finish/share

Jika 1 sesi test gagal, jangan buka layanan dulu.

### 2) Saat Event Berjalan

- Operator 1 fokus ke tamu (arah pose, flow cepat).
- Operator 2 (jika ada) fokus ke print dan troubleshooting.
- Gunakan 1 pola pelayanan:
  1. Pilih/cek event aktif
  2. Input customer (opsional) + voucher kalau ada
  3. Jalankan sesi foto
  4. Pastikan hasil keluar (print/share)
- Catat transaksi tambahan (extra print/add-on) saat itu juga.
- Setiap 30-60 menit:
  - cek sisa media print
  - cek suhu perangkat
  - cek ada antrian error atau tidak

### 3) Setelah Event Selesai

- Hentikan sesi baru.
- Pastikan semua sesi pending sudah selesai sync.
- Rekap singkat:
  - jumlah sesi
  - jumlah print
  - omzet masuk
  - kendala utama
- Backup data penting (jika perlu).
- Matikan alat dengan aman.

## C. SOP Uang Masuk (Supaya Tidak Bingung)

Pakai format sederhana:

- `Uang Kontrak Event` (dibayar sebelum/hari H)
- `Uang Tambahan di Lokasi` (extra print/add-on)
- `Total Uang Masuk`
- `Biaya Operasional` (transport, parkir, helper, dll)
- `Sisa Bersih`

Catat di spreadsheet/notebook setiap event. Jangan ditunda.

## D. SOP Jika Ada Masalah (Panic Plan)

### 1) Printer gagal

- Cek kertas/tinta/ribbon.
- Restart printer 1x.
- Jika masih gagal:
  - lanjutkan sesi foto dulu
  - simpan antrian print
  - informasikan tamu: print diproses bertahap

### 2) App error/freeze

- Screenshot error kalau sempat.
- Restart app.
- Kalau perlu restart device.
- Jika tetap gagal: pindah ke device cadangan.

### 3) Station putus

- Tetap layani mode lokal (jika memungkinkan).
- Catat sesi manual.
- Sync ulang setelah koneksi pulih.

### 4) Kamera eksternal tidak konek

- Cek kabel/OTG/power.
- Re-scan + pairing + connect.
- Jika tetap gagal: fallback ke kamera Android supaya layanan tidak berhenti.

## E. SOP Pelayanan (Biar Repeat Order)

- Sambut cepat: maksimal 10 detik sejak tamu datang.
- Instruksi jelas: “pose 1, pose 2, pose 3”.
- Tunjukkan preview singkat sebelum final.
- Tutup dengan call-to-action:
  - “Kalau suka hasilnya, bisa share dan tag event ini.”

## F. Target Sederhana Bisnis (Awal)

Gunakan target mudah dulu:

- Target sesi per jam
- Target minimal omzet per event
- Target error print < 5%
- Target komplain tamu = 0

Evaluasi tiap selesai event, jangan nunggu akhir bulan.
